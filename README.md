# plugmap

Plug structured JSON map payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/plugmap/

## Install / run

```bash
git clone https://github.com/theworker02/plugmap.git
cd plugmap
node src/cli.js
node --test
```
